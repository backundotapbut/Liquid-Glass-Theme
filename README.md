# LiquidGlassTheme [W.I.P]

Тема в стиле «жидкого стекла» для PulseSync. Это объединение и доработка двух
аддонов — **Minimalistic Wave Tab** (минималистичная страница «Моя волна») и
**YetAnotherBlurTheme** (стеклянные подложки и размытие), с собственными
дополнениями: настройки вида боковой панели, интеграция с ToVibe и
CoverDownloader, отдельные параметры стекла для плеера «Моя волна».

## Что делает тема

- Размытие и стеклянные подложки у плеера, панелей, диалогов, кнопок,
  всплывающих окон и закреплённых заголовков.
- Отдельные настройки стекла для полноэкранного плеера: плавное открытие,
  анимация смены обложки, плотность фона.
- Минималистичная «Моя волна»: чистое полотно с анимацией волны, ширина плеера,
  скрытие баннера обновления и блока артиста.
- Стекло элементов плеера «Моя волна»: шкала прогресса, кнопки управления,
  подсказка 18+.
- Три вида боковой панели: стандартный, прозрачный и жидкое стекло.
- Стекло формы ToVibe «Новый вайб» и кнопки скачивания обложки
  (если соответствующие аддоны установлены).

## Вид боковой панели

- **Стандартный** — панель как в приложении, без изменений.
- **Прозрачный** — подложка и рамки убраны полностью: сквозь панель видны
  лучи анимации волны.
- **Жидкое стекло** — полупрозрачная панель с размытием, лёгкой рамкой,
  бликами и тенью.

Параметр выбирается в настройках аддона: **Интерфейс → Вид боковой панели**.

## Настройки

Все параметры собраны в разделах настроек аддона в PulseSync — каждая группа
подписана по смыслу: стекло и размытие, всплывающие окна, плотность подложек,
анимации, «Моя волна», стекло плеера «Моя волна», интеграции и интерфейс.
